# Erthal Soares Advogadas — Website Institucional

Website institucional desenvolvido para o escritório **Erthal Soares Advogadas** (Curitiba - PR), especializado em Direito do Trabalho, Direito de Família, Direito do Consumidor, Direito Previdenciário e Direito Civil & Sucessões.

## Tecnologias Utilizadas
- **Framework:** Next.js 16 (App Router com Turbopack)
- **Biblioteca Base:** React 19
- **Linguagem:** TypeScript
- **Estilização:** Tailwind CSS v4 + Vanilla CSS Custom Tokens
- **Animações & Scroll:** GSAP 3.15 + ScrollTrigger + @gsap/react + Lenis Smooth Scroll
- **Ícones:** Lucide React

## Identidade Visual & Paleta 60-30-10
- **Cor Primária (30%):** Marrom Café `#5C4026`
- **Cor de Ação / CTAs (10%):** Ouro Amarelo `#F4A938`
- **Fundo Claro (60%):** Off-White Suave `#FBFBF9` (e Branco `#FFFFFF`)
- **Fundo Escuro:** Marrom Escuro Profundo `#302013`
- **Tipografia:** Cormorant Garamond (títulos) + Inter (leitura)

## Conformidade Ética
- Cumprimento rigoroso do **Provimento 205/2021 do CFOAB** e do Código de Ética e Disciplina da OAB.
- Ausência de mercantilização ou captação indevida de clientela.

## Rotas Principais
- `/`: Página principal institucional (Hero com Parallax, Pilares, Sobre, Áreas de Atuação com Sobreposição Pinada, Conteúdo Educativo, Como Atuamos, FAQ e Contato).
- `/links`: Página de bio rápida (Split-screen 50/50 desktop e background geométrico SVG mobile).
- `/sitemap.xml` e `/robots.txt`: SEO e rastreabilidade automatizados.
